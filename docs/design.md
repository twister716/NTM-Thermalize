# NTM: Thermalize 設計メモ

NTM - Continuum の防具と Tough As Nails（TAN）の体温をつなぐための仕様。
決まったことと、まだ決まっていないことを分けて書く。

## 前提：TANの体温

TANの体温は5段階：極寒（ICY）→ 寒い（COLD）→ 普通（NEUTRAL）→ 暖かい（WARM）→ 暑い（HOT）。
段階は整数なので、小数の値は最後に**切り捨て**て段階に直す。

## 対象になる防具

体温への影響は、**4部位すべてに防具を着たときだけ**出る。1部位でも欠けていれば何もしない。

### 全身スーツ（一覧に載っているもの）

外装材は等倍、蒸れる。温度変化の上限はスーツごとに決める（コードの `ThermalSuits` の表）。

| グループ | スーツ | 上限 |
|---|---|---|
| ハズマット系（防護服） | ハズマット、発展型ハズマット、高性能ハズマット、PaA製戦闘用ハズマット、タウルン、トレンチマスター | 1 |
| ハズマット系（防護服） | 除染作業用防護服 | 2 |
| 環境スーツ系 | M1TTY式環境対応スーツ、スチームスーツ | 1 |
| 環境スーツ系 | 防火近接、ディーゼル駆動式、HEVマークIV | 2 |
| パワーアーマー系 | T-51b | 1 |
| パワーアーマー系 | 鋼鉄のレンジャー、AJR、レムナント、NCRレンジャー、月面用サイバネティック、DNTナノスーツ、Fau | 2 |

### その他のフルセット（一覧に載っていないもの）

- 4部位すべてに何かしらの防具を着ていれば、自動でこれになる（違う種類が混ざっていてもよい）
- NTMの鋼鉄やチタン、バニラの鉄や金、他のModの防具も含む
- 外装材の効果は**半分**、温度変化の上限は1、**蒸れない**

### TANの羊毛の防具・葉の防具

- その部位に付けた外装材は**0として数える**（改造しても変わらない）

## 外装材（クラッディング枠の改造）

外装材は1部位ごとに値を持ち、**4部位の合計を切り捨てた段階数**だけ効く。

| パーツ | 1部位あたり | 4部位の合計 |
|---|---|---|
| 断熱外装材（暖かくする） | 0.25 | 1段階 |
| 上位の断熱外装材（暖かくする＋放射線耐性） | 0.5など | 2段階など |
| 冷却外装材（涼しくする） | −0.25など | −1段階など |

- 合計が0.75なら0段階（4部位すべてに付けないと効かない）
- その他のフルセットでは値が半分になる（断熱外装材を4部位付けても0.5で0段階）
- NTMの外装材枠は1部位に1つで、放射線対策の外装材（鉛など）と取り合いになる。両方欲しければ上位品を使う

## 空調

| アイテム | ID | 効果 | 消費電力 |
|---|---|---|---|
| 空調 | `air_conditioner` | 蒸れを防ぐ | 10HE/s |
| 熱均衡空調 | `thermal_equilibrium_air_conditioner` | 蒸れを防ぎ、体温を「普通」に近づける（スーツの上限まで） | 25HE/s |
| 無消費空調 | （アイテムではない） | 蒸れを防ぐ | なし |
| 無消費熱均衡空調 | （アイテムではない） | 熱均衡空調と同じ | なし |

### 空調のレシピ

| 空調 | 作る場所 | 材料 |
|---|---|---|
| 空調 | 組立機（200tick、500HE/t） | 武器鋼の機構×2、ハイス鋼のボルト×2、集積回路基板×1 |
| 熱均衡空調 | 組立機（200tick、1000HE/t） | サターナイトの機構×2、デッシュ複合プレート×2、アルミプレート×4、多用途集積回路×2、クリオゲル1000mB |

- 空調・熱均衡空調は**レギンスの脚専用枠だけ**に付けられる
- 動く条件：電気で動く全身スーツを4部位着ていて、全部位に電気が残っている（NTMの `ArmorFSB.hasFSBArmor`。暗視ゴーグルと同じ判定）
  - NTMの改造台は付けられる防具を部位でしか判断できないので、電気で動かない防具にも付けられてしまう。その場合は動かない（説明文に「電動フル装備が必要」と書く）
- 電気は、空調を付けた**レギンスの電池から1秒ごと**に引く。クリエイティブでは減らない
- 最初から付いている空調と、レギンスに付けた空調のうち**強いほう**が動く。電気を使うのは、付けた空調のほうが強いときだけ
  - 例：レムナント（無消費空調）に熱均衡空調 → 熱均衡として動き、25HE/sを使う
  - 例：DNT（無消費熱均衡空調）に空調 → 無消費熱均衡のまま。電気は使わない
- **Gキー**（キー設定で変更可）でオン／オフ。無消費空調もオフにできる
  - オフの印はレギンスに保存されるので、脱いで着直しても残る
  - 切り替えるとチャットに「空調：オン／オフ」と出る

## 説明文（フル装備ボーナス欄）

一覧に載っている全身スーツの各部位の説明文で、NTMの「フル装備ボーナス：」欄に行を足す。欄がない防具（ハズマットなど）は、見出しごと、アイテム固有の説明の直後に足す（最初の空行か、NTMの耐性の欄「フル装備時の耐性：」などの、どちらか先に出てくるほうの手前）。ユーフェミウムには何も足さない。

| 行 | 出るスーツ | 色 |
|---|---|---|
| 保温 | 蒸れるスーツ（防火近接以外。最初から空調が付いていても出す） | 金 |
| 温度均衡 | 防火近接スーツ | 金 |
| 空調 | 最初から無消費空調が付いているスーツ | 水色 |
| 熱均衡空調 | 最初から無消費熱均衡空調が付いているスーツ | 水色 |
| 温度変化の上限：N | すべて | 青 |

## 体温の計算順

1. 4部位すべてに防具を着ていなければ、何もしない
2. **ベース**を決める
   - 普通は、TANが周りの環境から計算した体温
   - 防火近接スーツは「普通」
3. 温度の調整
   - **熱均衡空調が動いているとき**：ベースから「普通」に向かって、温度変化の上限まで近づける。外装材は無視する
   - **動いていないとき**（付いていない、オフ、電池切れ）：外装材の合計（その他のフルセットは半分）を切り捨てて段階数にし、±上限で制限してからベースに足す
4. **蒸れ**：蒸れるスーツで、空調（どの種類でも）が動いていなければ、最後に+1段階。上限とは関係なく足す
5. 5段階（極寒〜暑い）の範囲に収める
6. **防具だけで極寒・極暑にしない**
   - 結果が極暑でも、外（TANが環境から計算した体温）が極暑でなければ「暖かい」に止める
   - 結果が極寒でも、外が極寒でなければ「寒い」に止める
   - 外がもともと極暑・極寒のときはそのまま。外装材で和らげることはできる

例：高性能ハズマット、断熱外装材を4部位、空調なし、極寒の場所
→ 極寒 →（外装材+1）寒い →（蒸れ+1）普通

熱均衡空調を外装材の代わりにした理由：
- 何を付けても変化は上限まで、と説明できる
- 電池切れやオフのときは外装材が代わりに働くので、両方付ける意味がある
