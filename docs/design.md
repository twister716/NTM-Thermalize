# NTM: Thermalize 設計メモ

NTM - Continuum の防具と Tough As Nails（TAN）の体温をつなぐための仕様。
決まったことと、まだ決まっていないことを分けて書く。

## 前提：TANの体温

TANの体温は5段階：極寒（ICY）→ 寒い（COLD）→ 普通（NEUTRAL）→ 暖かい（WARM）→ 暑い（HOT）。
段階は整数なので、小数の値は最後に**切り捨て**て段階に直す。

## 対象になる防具

体温への影響は、**4部位すべてに防具を着たときだけ**出る。1部位でも欠けていれば何もしない。

### 全身スーツ（一覧に載っているもの）

被覆は等倍、蒸れる。温度変化の上限はスーツごとに決める（コードの `ThermalSuits` の表）。

| ハズマット系（防護服） | 除染作業用防護服 | 2 |

### その他のフルセット（一覧に載っていないもの）

- 4部位すべてに何かしらの防具を着ていれば、自動でこれになる（違う種類が混ざっていてもよい）
- NTMの鋼鉄やチタン、バニラの鉄や金、他のModの防具も含む
- 被覆の効果は**半分**、温度変化の上限は1、**蒸れない**

### TANの羊毛の防具・葉の防具

- その部位に付けた被覆は**0として数える**（改造しても変わらない）

## 被覆（被覆枠の改造）

被覆は1部位ごとに値を持ち、**4部位の合計を切り捨てた段階数**だけ効く。

| 被覆 | ID | 1部位あたり | 放射線耐性 |
|---|---|---|---|
| 羊毛の断熱被覆 | `wool_insulation_cladding` | +0.25 | なし |
| アスベストの断熱被覆 | `asbestos_insulation_cladding` | +0.5 | なし |
| アルミ加工-フェロウランの断熱被覆 | `ferrouranium_insulation_cladding` | +0.5 | +0.25 |
| 銅の冷却被覆 | `copper_cooling_cladding` | −0.25 | なし |
| 黒鉛の冷却被覆 | `graphite_cooling_cladding` | −0.5 | なし |
| クリオ加工-フェロウランの冷却被覆 | `ferrouranium_cooling_cladding` | −0.5 | +0.25 |

- 合計が0.75なら0段階（4部位すべてに付けないと効かない）
- その他のフルセットでは値が半分になる（断熱被覆を4部位付けても0.5で0段階）
- NTMの被覆枠は1部位に1つで、放射線対策の被覆（鉛など）と取り合いになる。両方欲しければ上位品を使う

## 空調

| アイテム | ID | 効果 | 消費電力 |
|---|---|---|---|
| 空調 | `air_conditioner` | 蒸れを防ぐ | 10HE/s |
| 熱均衡空調 | `thermal_equilibrium_air_conditioner` | 蒸れを防ぎ、体温を「普通」に近づける（スーツの上限まで） | 25HE/s |
| 無消費空調 | （アイテムではない） | 蒸れを防ぐ | なし |
| 無消費熱均衡空調 | （アイテムではない） | 熱均衡空調と同じ | なし |

### 空調のレシピ

| 空調 | 作る場所 | 材料 |
|---|---|---|
| 空調 | 組立機（200tick、500HE/t） | 武器鋼の機構×2、ハイス鋼のボルト×2、集積回路基板×1 |
| 熱均衡空調 | 組立機（200tick、1000HE/t） | サターナイトの機構×2、デッシュ複合プレート×2、アルミプレート×4、多用途集積回路×2、クリオゲル1000mB |

- 空調・熱均衡空調は**レギンスの脚専用枠だけ**に付けられる
- 動く条件：電気で動く全身スーツを4部位着ていて、全部位に電気が残っている（NTMの `ArmorFSB.hasFSBArmor`。暗視ゴーグルと同じ判定）
  - NTMの改造台は付けられる防具を部位でしか判断できないので、電気で動かない防具にも付けられてしまう。その場合は動かない（説明文に「電動フル装備が必要」と書く）
- 電気は、空調を付けた**レギンスの電池から1秒ごと**に引く。クリエイティブでは減らない
- 最初から付いている空調と、レギンスに付けた空調のうち**強いほう**が動く。電気を使うのは、付けた空調のほうが強いときだけ
  - 例：レムナント（無消費空調）に熱均衡空調 → 熱均衡として動き、25HE/sを使う
  - 例：DNT（無消費熱均衡空調）に空調 → 無消費熱均衡のまま。電気は使わない
- **Gキー**（キー設定で変更可）でオン／オフ。無消費空調もオフにできる
  - オフの印はレギンスに保存されるので、脱いで着直しても残る
  - 切り替えるとチャットに「空調：オン／オフ」と出る

## 体温の計算順

1. 4部位すべてに防具を着ていなければ、何もしない
2. **ベース**を決める
   - 普通は、TANが周りの環境から計算した体温
   - 防火近接スーツは「普通」
3. 温度の調整
   - **熱均衡空調が動いているとき**：ベースから「普通」に向かって、温度変化の上限まで近づける。被覆は無視する
   - **動いていないとき**（付いていない、オフ、電池切れ）：被覆の合計（その他のフルセットは半分）を切り捨てて段階数にし、±上限で制限してからベースに足す
4. **蒸れ**：蒸れるスーツで、空調（どの種類でも）が動いていなければ、最後に+1段階。上限とは関係なく足す
5. 5段階（極寒〜暑い）の範囲に収める
6. **防具だけで極寒・極暑にしない**
   - 結果が極暑でも、外（TANが環境から計算した体温）が極暑でなければ「暖かい」に止める
   - 結果が極寒でも、外が極寒でなければ「寒い」に止める
   - 外がもともと極暑・極寒のときはそのまま。被覆で和らげることはできる

例：高性能ハズマット、断熱被覆を4部位、空調なし、極寒の場所
→ 極寒 →（被覆+1）寒い →（蒸れ+1）普通

熱均衡空調を被覆の代わりにした理由：
- 何を付けても変化は上限まで、と説明できる
- 電池切れやオフのときは被覆が代わりに働くので、両方付ける意味がある

## NTM Space 連携（気温）

NTM Space が入っているときだけ働く。TANの気温の計算に、星ごとの気温と、真空・部屋の判定を足す。
Kerbin（地上世界）はさわらない。

### ① 星全体の気温

その星のどこでも同じ（地下も含む）。TANの「地下は常温」「夜は冷える」「雨」「高さ」の補正は、星の上では使わない。

1. 恒星（Kerbol）からの距離で5段階に分ける。衛星は親の惑星と同じ距離として扱う
   - 日差しの強さ（Kerbin = 1、距離の2乗に反比例）で区切る
   - 4以上：極暑 ／ 1.5以上：暑い ／ 0.7以上：常温 ／ 0.25以上：寒い ／ それ未満：極寒
2. 0.5気圧以上の星は1段階暖かくする（温室効果）
3. 極地のバイオーム（タグ `ntmthermalize:colder_biomes`）は1段階寒くする
   - 最初に入れるもの：Laythe Polar、Duna Polar、Duna Polar Hills

| 星 | 距離 | 気圧 | 気温 |
|---|---|---|---|
| Moho | 0.39 | 0 | 極暑（真空の例外） |
| Eve | 0.72 | 5.0 | 極暑（暑い＋温室効果） |
| Mun・Minmus | 1.0 | 0 | 極寒（真空） |
| Duna | 1.52 | 0.1 | 寒い（極地は極寒） |
| Ike | 1.52 | 0 | 極寒（真空） |
| Dres | 3.0 | 0 | 極寒（真空） |
| Laythe | 5.1 | 0.6 | 寒い（極寒＋温室効果、極地は極寒） |
| Tekto | 9.3 | 1.5 | 寒い（極寒＋温室効果） |
| Thatmo | 30.1 | 0.005 | 極寒 |

### ② 真空

- 部屋の外で0.001気圧以下なら真空（NTM Space の真空の判定と同じ）
- 真空は極寒。ただし Moho は恒星に近すぎるので極暑
- 宇宙ステーションのある軌道も真空として扱う
- 真空では、TANの「近くの熱源で1段階変わる」効果を無しにする（熱を運ぶ空気がないため）

### ③ 呼吸できる空気で満たされた部屋

NTM Space の密閉された部屋の中で、空気が呼吸できる（NTM Space の「息ができる」判定）とき。

- 暖房も冷房もない：外の気温より1段階、常温に近づける（極寒→寒い、極暑→暑い）
- 暖房がある：外が寒い側（寒い・極寒）なら部屋全体が常温
- 冷房がある：外が暑い側（暑い・極暑）なら部屋全体が常温
- 暖房・冷房は、部屋の中と部屋に面しているブロックから探す
  - タグ `ntmthermalize:room_heat_sources`（暖房）、`ntmthermalize:room_cooling_sources`（冷房）に入っているブロックだけ
  - 今は空。冷房・暖房のブロックを作ったら入れる（予定）
- 焚き火などの普通の熱源・冷却源は、TANと同じく近くにいるときだけ±1（部屋全体には効かない）
- 部屋の暖房・冷房探しは5秒に1回だけやり直す（重くしないため）

### 室温計

- インベントリにあれば、左上に「室温：〇〇」を出し続ける（1秒ごとに更新、岩盤鉱石密度測定器と同じ表示）
- 室温は防具を脱いだときの体温の行き先（場所の気温＋③の部屋・真空の補正）
- 丸い文字盤の針が室温を指す。針は17段階で、2tickに1段階ずつ動く（気温1段階＝4段階）
- 中身が変わっても、手を下げ直す動きはしない
- レシピ：作業台で、上段の真ん中に M、中段に P T P、下段の真ん中に P（M＝小さな水銀のしずく、T＝TANの温度計、P＝鋼鉄板）

### ④ 防護服

①〜③で決まった気温に対して、保温・蒸れ・空調はいつもどおりかかる。
